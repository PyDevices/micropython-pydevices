# Files and pins

| Path | What it is |
|---|---|
| [`build_mp.py`](https://github.com/PyDevices/micropython-pydevices/blob/main/build_mp.py) | The build command: [every option](build-command.md). It fills in `micropython/`, [`modules/`](https://github.com/PyDevices/micropython-pydevices/tree/main/modules) and `deps/` if they're missing, prepares the MicroPython tree and runs the port's own `make`. |
| [`DEPENDENCIES.lock`](https://github.com/PyDevices/micropython-pydevices/blob/main/DEPENDENCIES.lock) | Everything [`build_mp.py`](https://github.com/PyDevices/micropython-pydevices/blob/main/build_mp.py) fetches, one `<name> <url> <commit>` line each: the MicroPython commit everything applies to; the modules it clones when one isn't there; [omnipython-lvgl](https://github.com/PyDevices/omnipython-lvgl), LVGL with its bindings and a port per interpreter, which a build with `lvgl` (or `all`) fetches into `modules/.omnipython-lvgl`; esp-vision; and the toolchains: ESP-IDF, emsdk, the TinyUSB the esp32 port builds on, and CircuitPython for `--interpreter circuitpython`. A toolchain's line ends in the tag its commit is. SDL2 for MinGW and the ESP-IDF components CircuitPython builds ask for are downloads, pinned by version. Beside sibling checkouts, modules are links to those checkouts instead. `python3 scripts/pins.py --list` prints the file as the build reads it. |
| [`provenance.json`](https://github.com/PyDevices/micropython-pydevices/blob/main/provenance.json) | The MicroPython pin and the checksum of every patch in [`patches/micropython/`](https://github.com/PyDevices/micropython-pydevices/tree/main/patches/micropython) and [`patches/tinyusb/`](https://github.com/PyDevices/micropython-pydevices/tree/main/patches/tinyusb). |
| [`modules/`](https://github.com/PyDevices/micropython-pydevices/tree/main/modules) | [`manifest.py`](https://github.com/PyDevices/micropython-pydevices/blob/main/modules/manifest.py), the manifest every build freezes; `all/`; the modules, [linked or cloned](modules.md); and `.esp-vision/`, the fetch script for [esp-vision's modules](../how-it-works/esp-vision.md). |
| [`patches/micropython/`](https://github.com/PyDevices/micropython-pydevices/tree/main/patches/micropython) | Our patch series, `0001-…` to `0042-…` (there is no `0026`, whose fix moved into [`patches/tinyusb/`](https://github.com/PyDevices/micropython-pydevices/tree/main/patches/tinyusb)), each justified in its own header. |
| [`patches/tinyusb/`](https://github.com/PyDevices/micropython-pydevices/tree/main/patches/tinyusb) | Patches to the TinyUSB the esp32 port builds on the S2, S3 and P4, which [`build_mp.py`](https://github.com/PyDevices/micropython-pydevices/blob/main/build_mp.py) applies to `deps/espressif__tinyusb` (at its `DEPENDENCIES.lock` tag) and builds in place of the port's own copy. |
| [`patches/micropython-lib/`](https://github.com/PyDevices/micropython-pydevices/tree/main/patches/micropython-lib) | micropython-lib's own fixes from after the commit MicroPython's `lib/micropython-lib` points at. A firmware that freezes those packages, and a board whose `/lib` you fill from the submodule, both get them. |
| [`patches/circuitpython/`](https://github.com/PyDevices/micropython-pydevices/tree/main/patches/circuitpython) | Our patches to CircuitPython, applied to `deps/circuitpython`. |
| [`patches/apply_patches.py`](https://github.com/PyDevices/micropython-pydevices/blob/main/patches/apply_patches.py) | Applies the MicroPython series, plus each module's own MicroPython patches, once, as one local commit. `--check` tests a change without applying it. |
| [`variants/`](boards.md#variants) | Our variants and the esp32 settings. |
| [`boards/circuitpython/`](boards.md#circuitpython-boards) | Boards CircuitPython has no definition for. |
| [`scripts/`](https://github.com/PyDevices/micropython-pydevices/tree/main/scripts) | `pins.py`, `exercise_build.sh`, `release_firmware.py`, `stage_firmware_page.py`, `serve_workbench.sh`, `freeze_list.py`, `update_provenance.py`, `ci_scope.py`, `wasm_provenance.py`. [Contributing](https://github.com/PyDevices/micropython-pydevices/blob/main/CONTRIBUTING.md) says what each is for. |
